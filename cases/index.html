용산 내과의원 A

내과 · 건강검진 · 실측 2026-11-19 08:56 · 진단 완료 · 제안서 전달

홈페이지가 크롤러에게 스크립트 762바이트만 돌려줍니다.

국가건강검진 지정, 비대면진료 시범사업, 외국인 진료까지 갖춘 병원입니다. 그런데 홈페이지에 접속하면 본문 대신 쿠키 인증 스크립트만 나오고, HTTPS로는 열리지 않으며, 구조화 데이터는 0건이었습니다. AI가 읽을 수 있는 것이 없었습니다.

확인된 값

  • GET http:// → 200, 본문 762바이트 (쿠키 생성 스크립트 + ?ckattempt=1 이동). 재시도도 동일
  • GET https:// → 연결 실패
  • application/ld+json 0건 — MedicalClinic·Physician 없음
  • robots.txt·llms.txt·sitemap.xml 모두 쿠키 인증 뒤에 있어 확인 불가

이미 갖고 있던 것 — 국가건강검진 지정(일반·위·대장·간), 비대면진료 시범사업 기관, 일차의료 만성질환관리 실시기관, 외국인 진료(Parkway Clinic), 초음파·골밀도·X-ray — 전부 자격은 있으나 AI에게는 없는 상태였습니다.

용산 한의원 B

한의원 · 8개 진료과목 · 실측 2026-11-19 20:50 · 진단 완료 · 제안서 전달

1차 출처가 블로그뿐이고, 그 블로그는 AI에게 닫혀 있습니다.

지도와 플레이스의 '홈페이지' 칸이 모두 네이버 블로그를 가리켰고, 자체 도메인 후보 6개는 모두 DNS 응답이 없었습니다. 그 블로그는 AI 봇 9종에 Disallow: / 를 선언하고 있고, 첫 응답은 제목과 iframe 한 줄뿐인 2,859바이트 껍데기였습니다.

확인된 값

  • 후보 도메인 6개 DNS 무응답 — 병원이 통제하는 웹 자산이 블로그뿐
  • blog.naver.com/robots.txt → AI 봇 9종 Disallow: / (플랫폼 정책, 병원이 바꿀 수 없음)
  • 블로그 첫 응답 2,859바이트 frameset, 목록 주소도 일반 크롤러에 차단
  • 포스트 페이지 application/ld+json 0건 · schema.org 문자열 0회
  • llms.txt·sitemap.xml 404
  • 구글 지도 '일요일 09:00–16:30' vs 심평원 공개 정보 '일요일 휴진' · 주소 '몰 D 2층 33호'와 '2032~2034, 2039호' 혼용

이미 갖고 있던 것 — 네이버 방문자리뷰 464 · 블로그리뷰 154 · 구글 평점 5.0(26개) · 첩약 건강보험 2단계 시범사업 참여 · 한방내과 전문의 1명과 8개 진료과목. 신뢰는 이미 쌓여 있었지만 AI에게 전달되는 통로가 없었습니다.

발리너스 본점

자사 사례 · 체형 밸런스 스튜디오 · 실측 2026-11-19 21:24 · 26,836자 재확인 · 진단 완료 · 자사 사례로 공개

사이트 4곳 중 AI가 읽는 곳은 한 곳, 그 한 곳의 이름이 회사와 달랐습니다.

운영 사이트 4곳을 직접 열어 확인했습니다. 한 곳은 첫 응답 본문이 8자였고, 한 곳은 글 0편이었으며, 유일하게 읽히는 사이트는 26,836자를 읽히지만 이름과 구조화 데이터가 다른 사업명으로 되어 있었습니다. 이름은 5종, 전화는 3종, 호수는 2개, 영업시간은 3가지로 갈려 있었습니다.

확인된 값

  • baliness81.com → 첫 응답 본문 8자 (425KB 중 나머지는 스크립트)
  • balancewave.co.kr → 26,836자 읽힘 (유일) · WordPress 7.1.5 · llms.txt 404
  • blog.balancewave.co.kr → 1,028자, 글 0편
  • llms.txt — 세 사이트 모두 404
  • 상호 5종 · 전화 3종 · 호수 92호/93호 · 영업시간 3가지(미등록 포함)

이미 갖고 있던 것 — 네이버 리뷰 38건(방문자 28·블로그 10), 구글 평점 5.0, 지도자 교육 17기·국내외 지도자 100명 이상, 워드프레스 글 49편. 자산은 있었지만 한 이름·한 주소로 묶이지 않아 AI가 하나의 실체로 인정하지 못했습니다.
